# Axiōma Web

The public, server-rendered marketing website for Axiōma. It uses React 19, TypeScript, Tailwind CSS 4, Vite, and TanStack Start (Nitro) with file-based routing.

## Run locally

```sh
pnpm install
pnpm dev
```

The site runs at `http://localhost:3000` (`vite dev --port 3000`).

## Stylesheet layout

`src/styles.css` (2,006 lines) was split verbatim in Phase 2; the entry point is now `src/styles/index.css` and it imports the partials in cascade order:

- `tokens.css` — raw palette (`@theme`) + semantic role tokens (`:root` / `.dark`) + Tailwind `@theme inline` shadcn aliases. This is the file a “small variation” re-tints.
- `base.css` — reset, `@layer base`, typography, `::selection`, skip link, `.sr-only`, page frame/shell.
- `primitives.css` — `.eyebrow`, `.button` variants, `.tag`, `.live-pill`, `.ledger-index`.
- `layout.css` — `.site-header`, `.nav-shell`, navigation states, `.theme-toggle`, `.site-footer` and footer grid.
- `sections.css` — all route sections (hero, ticket, dark-section panels, context-map, step grids, device/terminal, pricing, flow, about, contact, status, not-found) and responsive breakpoints.
- `motion.css` — `dossier-reveal` keyframes and `prefers-reduced-motion` handling; scroll-driven `animation-timeline: view()` with a `@supports not` fallback.

No CSS was rewritten during the split — it was moved verbatim — and `components.json` now points at `src/styles/index.css`.

## Theme toggle

A no-flash inline script in `src/routes/__root.tsx` sets `documentElement.classList.toggle("dark")` from `localStorage.theme` then `prefers-color-scheme`, before first paint (`suppressHydrationWarning` on `<html>`). `src/components/theme-toggle.tsx` is a three-state control (light / dark / system) built on `src/components/ui/toggle-group.tsx` (Radix Toggle Group) and writes `localStorage.theme`. The header renders it on desktop; on mobile it sits in the mobile menu. Tokens are semantic pairs per role (`--surface-*`, `--text-*`, `--rule*`, `--brand*`) so the editorial CSS keeps ownership of marketing surfaces and `--sidebar-*` / `--chart-*` shadcn groups were removed.

`public/site.webmanifest` uses `#f4f4f5` (light veil) for `theme_color` / `background_color`; `__root.tsx` emits two `theme-color` metas with `media` queries (`#f4f4f5` light, `#09090b` ink dark).

Fonts are self-hosted via `@fontsource-variable/instrument-sans` and `@fontsource-variable/geist-mono` imported in `src/styles/index.css`. The Google Fonts CDN link is gone.

## Quality gates

```sh
pnpm check          # Biome lint + format
pnpm build          # Vite + Nitro build (generates routeTree.gen.ts)
pnpm check-types    # tsc --noEmit (must run after build)
pnpm check-all      # check && build && check-types
```

`pnpm check-all` is the ordering-safe gate used by CI (`.github/workflows/web.yml` and `contracts.yml:web`), scoped to `axioma/web/**`. Biome coverage excludes `.output`, `routeTree.gen.ts`, `src/components/ui`, `.baseline`, and `scripts`.

Manual verification matrix (re-run before any release):

| Check | Routes | Themes | Widths |
|---|---|---|---|
| Visual pass | all six | light + dark | 360 / 768 / 1440 |
| Keyboard traversal (header, mobile menu, pricing tabs, theme toggle) | all six | light | 1440 |
| Reduced motion on | home, product | light | 1440 |

## Status page

`/status` reports daily availability from the live API via `src/lib/status.ts` (`fetchStatus` server function). Configure the upstream:

```sh
AXIOMA_API_URL=http://localhost:3000  # default; no trailing slash required
```

When `AXIOMA_API_URL` is unreachable or returns a non-2xx / malformed payload, the route fails closed to an honest “we could not load availability data” state (`StatusUnavailable`). The page consumes `POST /api-reference/readStatus` with `{ days: 90 }` and validates every `ServiceStatus` / `StatusDay` record before rendering.

## SEO

Per-route metadata is generated by `src/lib/seo.ts:pageMeta({ title, description, path })` — canonical, Open Graph (`og:*`), Twitter card, and default `og:image` (`/og.png` 1200×630). `src/routes/__root.tsx` adds site-wide defaults (`og:site_name`, `og:locale`, `og:image` dimensions, `twitter:card`) and JSON-LD `Organization` + `WebSite` blocks. `public/sitemap.xml` (six static URLs, `https://axioma.dev`) and `public/robots.txt` (`Sitemap:`) are static; `public/og.png` (`public/og.svg` source) is the 1200×630 social card.

## Contact

The contact page and footer subscribe use real `mailto:` links to `hello@axioma.dev`; there is no simulated form submission or backend dependency. Subscribing opens the visitor’s email client and says so on the page.
