# Axiōma Web

The server-rendered public site for Axiōma, built with React 19, TypeScript, Tailwind CSS 4, Vite, and TanStack Start.

## Run locally

```sh
pnpm install
pnpm dev
```

The site runs at `http://localhost:3003`.

## Routes

`/`, `/product`, `/impact`, `/pricing`, `/about`, `/contact`, and `/status`.

## Styles

`src/styles/index.css` imports:

- `tokens.css`: Proof-first palette and semantic tokens.
- `base.css`: reset, type scale, shells, focus, and skip link.
- `primitives.css`: buttons, panels, rows, state chips, divider grids, and footnotes.
- `layout.css`: header, navigation, theme toggle, section rhythm, and footer.
- `replay.css`: transcripts and the single orchestrated replay.
- `impact.css`: calculator, time split, coverage table, and sources.
- `sections.css`: route-specific responsive layout.
- `motion.css`: reduced-motion safeguards.

Instrument Sans and Geist Mono are self-hosted. `page-frame` and `page-sheet` remain unpainted wrappers. Green is used only for successful state.

## Quality gates

```sh
pnpm fix
pnpm check
pnpm build
pnpm check-types
pnpm test-impact
pnpm audit-figures
pnpm check-all
```

Build precedes type-check because it regenerates `src/routeTree.gen.ts`. `audit-figures` checks that publishable figures in route and content files trace to `src/content/research.ts` or `src/content/facts.ts`. CI runs the web job in `.github/workflows/contracts.yml`.

## SEO and social image

Metadata is generated by `src/lib/seo.ts`. `public/sitemap.xml` lists all seven routes. `public/og.svg` is the source card; run `pwsh scripts/gen-og.ps1` with local Chrome to regenerate the 1200×630 `public/og.png`.

## Status and contact

Set `AXIOMA_API_URL` for `/status`. An unreachable or malformed upstream returns the honest unavailable state. Contact and footer subscription open the visitor’s email client; this site stores nothing.
