# Axiōma Web — Decision Log

Companion to [WEB_UPLIFT_PLAN.md](WEB_UPLIFT_PLAN.md). Every decision below was
taken during the delta-grill before implementation. Decisions D1–D6 were
resolved in the plan; D7 onward were taken while executing it. New decisions are
appended at the end so the log reads chronologically.

## Decisions resolved in the plan

- **D1 — shadcn/ui: adopt narrowly.** Radix-backed primitives own interactive
  behaviour and accessibility only (pricing tabs, mobile navigation, theme
  toggle). The editorial CSS keeps every marketing surface. `button.tsx` is
  wired into real surfaces or deleted — it does not stay unused.
- **D2 — Dark mode: ship it.** Role-named semantic token pairs, a no-flash
  inline theme script, a three-state toggle, and `.dark-section` redesigned as
  a contrast band on dark pages rather than dark-on-dark.
- **D3 — Motion: code-driven scroll motion.** CSS `animation-timeline: view()`
  with a `@supports` fallback to the current load-time reveal. No Higgsfield, no
  generated video, no new runtime dependency.
- **D4 — Cloudflare Pages: skip.** Deployment (Nitro build, Dockerfile, Helm
  chart) is untouched.
- **D5 — Pricing: restructure to "talk to us".** Tier names, positioning notes,
  and feature lists survive; invented dollar figures and per-unit prices do not.
  `/pricing` explains what each tier covers and routes to a conversation. Real
  figures drop into `src/content/pricing.ts` later without a layout change.
- **D6 — Third-party skills: project scope only.** Installs run with the
  working directory pinned to `axioma/web` and land under
  `axioma/web/.claude/skills/`; `git status` from the repo root proves nothing
  landed outside `axioma/web`.

## Decisions taken during execution

- **D7 — Mono face: Geist Mono, self-hosted.** The site loaded Fragment Mono
  from the Google Fonts CDN while shipping the unused
  `@fontsource-variable/geist-mono` package. One answer, not two: the installed
  Geist Mono Variable wins, both font packages are self-hosted through
  `src/styles/index.css`, and the CDN `<link>`s are removed. This kills the
  render-blocking third-party request. If the Phase 5 `typeset` pass wants a
  different voice, it re-litigates `--font-mono` in `tokens.css` only.
- **D8 — Site URL: `https://axioma.dev`.** Canonicals, `og:url`, the sitemap,
  and JSON-LD need an absolute origin. The contact address is
  `hello@axioma.dev`, so `axioma.dev` is the brand's domain. It lives in one
  constant (`SITE_URL` in `src/content/site.ts`) so a change is one line.
- **D9 — Theme colours.** The browser-chrome `theme-color` values follow the
  real page background per theme: light `#f4f4f5` (veil), dark `#09090b` (ink).
  The manifest uses the light values. This replaces the three contradictory
  answers (`#0b0e12`, `#008236`, white) the audit found.
- **D10 — Static sitemap.** Six routes, no dynamic segments, and the pinned
  `@tanstack/router-core` exposes no server-handler route option. A static
  `public/sitemap.xml` is generated by hand. The escape hatch, if ever needed,
  is a Nitro server route — not a TanStack route.
- **D11 — No JS motion fallback hook.** `src/hooks/use-in-view.ts` stays
  unwritten. The CSS `@supports (animation-timeline: view())` guard already
  falls back to the existing load-time reveal, and the `motion` package stays
  out of `package.json`. If real-world browsers make the fallback inadequate,
  the hook is the first thing to add.
- **D12 — Theme toggle placement.** The three-state control sits in the header
  beside the navigation on desktop and inside the mobile menu on small screens.
  The mobile menu is the mobile header, so this satisfies "header, and in the
  footer on mobile" in spirit with one component and one code path.
- **D13 — grill-me not installed.** The delta-grill already happened: the plan's
  Section 2 audit is the grill transcript, and D1–D6 are its answers. Installing
  `grill-me` to re-ask them would be ceremony. `impeccable` was attempted but
  auto-targeted the repo root (`D:\Work\hackthons\ai-buildathon`, outside the
  plan's `axioma/web` boundary) and has no scoping flags, so per **D6** the
  install was abandoned — Phase 5 discipline passes are executed manually
  instead.
- **D14 — `SHADCN_PLAN.md` already gone.** The plan called for deleting it or
  reducing it to a pointer; the file is no longer present in the tree, so
  nothing to do. This decision log and the plan are the surviving record.
- **D15 — og image.** `public/og.png` is a 1200×630 card built from the brand
  palette (paper, ink, brand green) with the Axiōma wordmark and the
  "from symptom to resolution" line. It is a static asset; regenerate it if the
  Phase 5 winner changes the palette. The PNG is generated by
  `scripts/gen-og.mjs` (pure Node `zlib`, no external deps); `public/og.svg` is
  the vector source.
- **D16 — CI workflow.** `.github/workflows/contracts.yml` grew a `web` job
  after the plan was audited. Per the plan a dedicated `web.yml` is still added,
  scoped to `axioma/web/**` paths, with the correct build-before-types order
  (`pnpm check` → `pnpm build` → `pnpm check-types`) via the new
  `check-all` script. The `contracts.yml:web` job order was also corrected.
